# AV2 — API e Catálogo de Livros

Este projeto reúne as duas atividades:
- `api-livros/`: API Python + Flask (Revisão 1).
- `frontend-livros/`: interface React + Vite (Revisão 2).

Consulte o README de cada pasta para instalar e executar. Para testar a integração,
inicie primeiro o Flask e depois o Vite, mantendo ambos em execução.
